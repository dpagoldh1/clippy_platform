# Standard Operating Procedure

## Purpose

Run and verify the SAS Hello World program in this repository.

## Prerequisites

- SAS is installed and available through SAS Studio, SAS Enterprise Guide, or the SAS command line.
- The repository has been cloned or is available locally.

## Procedure

1. Open `hello_world.sas` in a SAS environment.
2. Submit or run the program.
3. Confirm that the SAS log contains:

   ```text
   Hello, world!
   ```

4. Confirm that the SAS log reports no errors.

## Validation

The procedure is successful when `Hello, world!` appears in the log and the program completes without errors.

## Troubleshooting

- If the file cannot be found, verify that the SAS session is using the repository directory.
- If SAS is unavailable, install SAS or open the file in an approved SAS environment.
- If errors appear in the log, review the first error message and rerun the program after correcting the issue.
